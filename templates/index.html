Character CNN Architecture

Feedforward ConvNet
Input Layer: (B, 1, 28, 28) Normalized Grayscale Character
Conv Block 1: Conv2D(1→32, 3×3) + BatchNorm + ReLU → Conv2D(32→64, 3×3) + BatchNorm + ReLU + MaxPool(2×2) → Dropout(0.2)
Conv Block 2: Conv2D(64→128, 3×3) + BatchNorm + ReLU + MaxPool(2×2) → Dropout(0.25)
Conv Block 3: Conv2D(128→128, 3×3) + BatchNorm + ReLU + AdaptiveAvgPool(4×4) → Dropout(0.25)
Dense Classifier: Linear(2048→256) + BatchNorm + ReLU + Dropout(0.4) → Linear(256→Classes)

Sequence CRNN (Word) Architecture

CNN + BiGRU + CTC
Input Layer: (B, 1, 32, 128) Aspect-Scaled Handwritten Word
CNN Feature Extractor: 5-stage Conv2D hierarchy collapsing height to 1 while preserving sequence length (T=32)
Recurrent BiGRU: 2-layer Bidirectional GRU (Hidden Size 128, Dropout 0.2) modeling character language transitions
CTC Decoding: Linear(256→37) → Greedy Best Path / Prefix Beam Search CTC decoder with blank collapse
Key Advantage: Eliminates individual character segmentation errors for cursive and overlapping handwriting!
